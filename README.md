# rocom-pets

跨平台桌面宠物：把《洛克王国：世界》里的宠物放到桌面上 —— 模型、动作、叫声都是游戏里那一份，
由一个原生运行时（Rust + wgpu）在桌面上播放与交互。宠物按需启用，可多只同时在场。

**程序不带任何游戏素材**：在配置窗口里指定自己的游戏安装目录，随程序附带的导出器按需把选中的
宠物导到本地生成「宠物包」。运行时不读游戏内存、不注入进程、不联网。

![配置窗口、预览窗口与桌面上的点点](docs/screenshot.webp)

## 主要功能

**桌面上的宠物**

- 待机 / 走动 / 奔跑 / 睡觉，透明置顶；多只同时在场，按图鉴号整条进化链归成一个包；
- 鼠标交互按**轮廓**命中（透明部分点不到）：受惊、摸头、拎起来拖放 —— 拎起的只是被点中的那只；
- 宠物之间会互相注意到并打招呼，受惊会跑开，凑近了还会演一段跨宠互动；
- 声音**两层**：嗓子发出来的叫声（开心 / 震惊 / 惊恐 / 伤心 / 生气 / 炫耀 / 放松 / 警觉 / 召唤九种情绪）
  加上身体动静的动作音效；嗓音可调（游戏里那个 −100～100 的 `voice`），默认小声、托盘可静音，
  自己叫的那些一分钟至多一次；
- 「眼神」跟着**性格**走（天真 / 开朗 → 微笑，懒散 / 悠闲 → 困倦，胆小 → 哭哭，急躁 → 生气），
  做动作时的脸按游戏里每段动画自带的曲线逐帧换 —— 待机时会眨眼；
- **异色**与**炫彩**两种稀有外观：异色是美术另做的一整套材质；炫彩有无炫彩 / 黑白隐藏 / 常规炫彩 /
  暗夜拾光 / 狂欢怪谈 / 铅字幻梦 / 月涌狂想，常规炫彩再挑配色与粒子（39 组 × 4 种，编号与游戏一致），
  每个赛季的传说精灵有自家赛季炫彩；两者互不影响，异色炫彩也行；
- 多块屏当成一整个桌面：拖动、走动、互相打招呼都能跨屏（上下摞着放的屏只能拖过去）；
  记得每只站在哪块屏，下次启动站回原处；从配置窗口添加的宠物出现在配置窗口所在的那块屏上；
- 点击穿透开关：开着的时候宠物只是看着，鼠标直接落到底下的窗口上。

**托盘菜单**：点击穿透、静音叫声、召回宠物；帧率（20 / 30 / 60）、大小倍率（50% / 100% / 150% / 自定义）、
叫声音量（静音 / 30% / 60% / 100%）三组档位；宠物预览、首选项、重新载入、退出。
在场只数在图标的悬停提示里。

**配置窗口**（托盘「首选项」，或 `rocom-pets --settings`）—— 改什么都即时生效，没有「保存」按钮，
顶上那条给撤销：

- **常用配置**：游戏目录、目标帧率、整体大小、叫声音量、启动就穿透；
- **宠物包**：以宠物链为单位的一张表（图鉴号、整条链「喵喵 → 喵呜 → 魔力猫」、形态数、导没导），
  多选后批量「导出 / 更新」；已导出的能预览、上桌、删除；
- **活跃宠物**：逐只展开，改形态、异色 / 炫彩、大小、性格、嗓音；底下是这只的**动作表**，
  点一格就在桌面上当场播一次。

**预览窗口**（托盘「宠物预览」，或 `rocom-pets --preview`）：左边宠物链列表（可搜形态名或图鉴号），
右边转着看模型 —— 左键拖转视角、右键拖平移、滚轮缩放、双击复位；切形态、换眼神 / 异色 / 炫彩 / 动作，
换底色（默认是游戏精灵盒子给这一系的那个色，也可自定义 `#rrggbbaa`），听叫声（原声 / 粗嗓门 / 婉转声），
把当前那段动作**存成表情包**（64～512px、20 / 25 / 50fps、透明或纯色底、GIF 或无损 WebP）。
看的那条链还没导出就在窗口里直接导。

**网页版**：[rkpet.whoisnian.com](https://rkpet.whoisnian.com) —— 与预览窗口同一份渲染编成 wasm
在浏览器里跑（需要 WebGPU），不用装东西、不用游戏目录，看模型、换炫彩、听叫声、存表情包。

## 支持平台

| 平台 | 状态 |
| --- | --- |
| **Windows 10+** | 实机验过：上桌、置顶、点击穿透、拖放、托盘；多屏（分辨率 / 缩放不同）跨屏拖动与行走 |
| **KDE Plasma Wayland** | 开发环境（Plasma 6.x / kwin_wayland），日常在跑；要 Vulkan 驱动与 `xdg-desktop-portal-kde` |

GNOME 等不实现 wlr-layer-shell 的合成器不在支持范围，也不做 X11 回退。

## 下载与运行

从 [Releases](https://github.com/whoisnian/rocom-pets/releases) 取分发件，**每个平台各一个文件**，
导出器已打在里面（自包含，不必装 .NET）：

- `rocom-pets-<版本>-windows-x64.exe`：拷到哪儿都行，双击即可，不需要 VC++ 运行库；
- `rocom-pets-<版本>-linux-x64`：`chmod +x` 后运行；`rocom-pets --install-desktop` 把桌面入口与图标
  装到 `~/.local/share` 下，启动器与托盘就有图标了。

第一次跑：

1. 启动后托盘里点「首选项」，在「常用配置」填**游戏安装目录**（自己找 `Win64/NRC/Content/Paks`）；
2. 到「宠物包」页勾选要的宠物链 →「导出 / 更新选中」，导出器从游戏 pak 直接读资产生成宠物包
   （头一次会顺带导炫彩共享素材）；
3. 「活跃宠物」页「添加宠物」，或在「宠物包」页对已导出的点「上桌」。

宠物包在 `%LOCALAPPDATA%\rocom-pets\packs\`（Windows）/ `~/.local/share/rocom-pets/packs/`（Linux），
一个图鉴号一个 `.rkpet2`；配置与在场阵容在 `%APPDATA%\rocom-pets\` / `~/.config/rocom-pets/`
（`config.toml` + `roster.toml`），下次启动自动恢复阵容与各自的位置。

**没有内置的全局热键**：要快捷键就在系统里把自定义快捷键绑到下面这几条，键位归系统管，
桌宠一个组合键都不抢：

```sh
rocom-pets --toggle-passthrough   # 切换点击穿透
rocom-pets --recall               # 把宠物召回主屏中间
rocom-pets --reload               # 手改完 config / roster 后让它重读
rocom-pets --quit                 # 退出
rocom-pets --settings             # 打开配置窗口
rocom-pets --preview              # 打开预览窗口
```

Windows 上双击不会有黑窗口；从 cmd / PowerShell 里 `set RUST_LOG=info` 再启动能看日志。
